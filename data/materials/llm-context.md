# Контекстное окно и структурированный вывод

Контекстное окно (context window) — ограниченный объём токенов, который модель может обработать за один запрос. В бюджет входят системные инструкции, история диалога, текущий вопрос, схемы инструментов, их аргументы и результаты. Место для ответа также ограничено выбранной моделью и параметром max_tokens.

При переполнении контекста приложение может удалить самые старые полные пары вопроса и ответа. Архив в PostgreSQL при этом сохраняется отдельно. При продолжении незаконченного ответа полезно оставить его конец. Оценка токенов по размеру текста приблизительна; точные значения usage сообщает провайдер, если поддерживает такую статистику.

Структурированный вывод (structured output) задаёт формат решения модели, например JSON с закрытым набором действий и аргументами. Приложение проверяет JSON по строгой схеме: неизвестные поля, неподходящие типы, нечисловая confidence и неизвестные маршруты отклоняются. Валидная схема не доказывает истинность фактов или наличие прав.

При native tool calling модель возвращает имя функции, аргументы и идентификатор вызова. Приложение сверяет имя с разрешённым каталогом и валидирует аргументы. Итоговый ответ получает результат с тем же tool_call_id; на этом шаге новые инструменты отключены. Некорректное решение не запускает скрытый повтор генерации.
