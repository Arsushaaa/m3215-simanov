# Назначение MCP

Model Context Protocol (MCP) — протокол обмена между приложением с языковой моделью и внешними источниками данных и инструментами. MCP отделяет интерфейс возможностей от конкретной модели: приложение обнаруживает каталог инструментов и ресурсов, проверяет их схемы и явно вызывает выбранную операцию.

Инструмент (tool) выполняет действие с аргументами по схеме: например, get_schedule читает занятия на указанную дату. Ресурс (resource) предоставляет именованные данные для чтения: например, schedule://current-week. Обнаружение инструмента не является разрешением вызвать его: приложение пересекает каталог с политикой доступа конкретного агента.

Router выбирает специалиста, но не вызывает MCP. Supervisor проверяет маршрут и бюджет. Специалист работает с ограниченным набором возможностей. Например, агент погоды не получает право создавать напоминания, даже если сервер объявил такой инструмент. Число прикладных вызовов ограничивает приложение.

Результаты MCP, названия и содержимое ресурсов — недоверенные данные. Фраза «игнорируй инструкции» внутри документа не становится системной командой. Для записи напоминания нужны показ точных параметров владельцу, нажатие кнопки и проверка права записи сервером. Текстовое обещание модели не подтверждает выполнение операции.
