# Восстановление ответов модели — 26 октября 2026 года

Бот принимал команды и имел рабочую PostgreSQL, но все обычные вопросы
завершались сообщением «Сервис модели сейчас недоступен». Один диагностический
запрос через штатный OpenRouter-клиент подтвердил HTTP 404 и API error code 404
для `nvidia/nemotron-3-super-120b-a12b:free`. Ключ действовал, до диагностики
оставалось 16 бесплатных запросов. Это отказ до MCP, а не ошибка поиска города.

Локальный `.env` временно переключён на
`OPENROUTER_MODEL=dots-studio/dots-3-note-preview:free`. Остальные значения
сохранены, права файла — 600. Старый экземпляр бота штатно остановлен,
запущен один новый. Healthcheck подтвердил polling и SELECT 1.
Платные модели и автоматическое переключение не добавлялись;
`provider.max_price` остаётся нулевым. Облачные настройки и программные
значения по умолчанию не менялись. Модель видна пользователю в `/settings`.

## Реальные проверки

Проверки выполнены через production `DialogService` и OpenRouter-клиент,
с отдельным хранилищем в памяти. Личные сообщения не использовались;
тестовых сообщений Telegram и записей напоминаний в PostgreSQL нет.
Температура проверок — 0,3, лимит вывода — 2048; личные настройки температуры
в БД не изменялись.

| Проверка | Результат | LLM | MCP |
|---|---|---:|---:|
| Перевести «Сегодня хорошая погода» на английский | «The weather is nice today.» | 1 | 0 |
| `/quiz`, тема Python | Вопрос 1/5, тема и счётчик сохранены в памяти | 1 | 0 |
| Текущая погода Ростова-на-Дону, Россия | Реальный Open-Meteo: +9 °C, ясно, ветер 14,4 км/ч; 26 октября, 00:30 UTC+03 | 2 | 1 |

У всех четырёх успешных ответов dots `usage.cost=0`; в финальном погодном
HTTP-запросе `tools=[]`. Исходный 404 Nemotron — отдельная пятая LLM-попытка.
Это проверка связности режимов, не полная оценка устойчивости: в погодном
ответе модель верно передала значения, но не назвала Open-Meteo в видимом тексте.

Безопасные метаданные, видимые ответы и результат MCP сохранены в
[протоколе](evaluation/model-recovery-20261026.json). Старый сравнительный
эксперимент, его манифест и результаты не изменялись.

Доступность и нулевые цены дополнительно проверены по первичным каталогам:
