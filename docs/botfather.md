# Лабби — профиль Telegram-бота

Лабби — учебный AI-помощник студента. Характер: дружелюбный, спокойный,
любознательный. Отвечает по-русски, объясняет понятными шагами, при нехватке
данных уточняет вопрос. Для режима перевода использует указанный пользователем
язык. Собственный режим лабораторной № 1 — `/quiz`, проверка знаний.

Ниже подготовлен профиль реализованной версии: все перечисленные команды
подключены к обработчикам. Регистрация команд в BotFather добавляет их в меню
Telegram; выполнение обеспечивает запущенное Python-приложение.

## `/setname`

```text
Лабби — AI-помощник студента
```

Если бот ещё не создан, предложенный username — `labbi_study_bot`.
Запасные варианты: `labbi_itmo_bot`, `labbi_ai_study_bot`.
Доступность имени проверяет BotFather при создании; она не проверена здесь.
Для уже созданного бота можно оставить его текущий username.

## `/setdescription`

```text
Привет! Я Лабби — твой AI-помощник в учёбе.

Объясняю программирование понятными шагами, перевожу тексты и помогаю проверить знания короткими вопросами.

Выбери режим: /study, /translate или /quiz, затем отправь сообщение.
Параметры ответов — /settings. Очистить историю — /reset.

Могу ошибаться: важные ответы проверяй по учебным материалам.
```

## `/setabouttext`

```text
AI-помощник студента: объясняю программирование, перевожу тексты и проверяю знания. Начни с /start.
```

## `/setuserpic`

Отправь BotFather изображение [labbi-avatar.png](../assets/branding/labbi-avatar.png).
Это робот-сова с раскрытой книгой на тёмном фоне. Центральная композиция
подходит для круглой обрезки Telegram, а отсутствие надписей делает аватар
читаемым в небольшом размере.

Аватар сгенерирован встроенным инструментом imagegen. Точный запрос сохранён
в [labbi-avatar-prompt.txt](../assets/branding/labbi-avatar-prompt.txt).

## `/setcommands`

После выбора бота отправь следующий блок одним сообщением, без начальных `/`:

```text
start - Начать работу и посмотреть команды
study - Объяснить учебную тему по программированию
translate - Перевести текст на выбранный язык
quiz - Проверить знания короткими вопросами
settings - Посмотреть и изменить параметры ответов
stop - Остановить ответ и ожидающие запросы
reset - Очистить историю текущего диалога
```

Готовый блок также сохранён в [botfather-commands.txt](botfather-commands.txt).

Режим `/quiz`: пользователь задаёт тему, бот задаёт один вопрос за раз.
После ответа даёт обратную связь и краткое объяснение; по просьбе пользователя
даёт подсказку до раскрытия ответа. Предлагаемый формат тренировки — пять
вопросов с итогом и рекомендацией, что повторить. Номер вопроса, тема и завершение
сохраняются в PostgreSQL, а нумерацию добавляет приложение. Подсказка не увеличивает
номер вопроса. Вопросы и ответы остаются
частью истории текущего пользователя, а смена режима очищает контекст
по требованиям лабораторной.

Команды `/tools`, `/why` и `/timezone` добавим при реализации лабораторной № 2.
Сейчас они не входят в публикуемый список.

## `/deletebot`

Эта команда удаляет бота и не нужна для настройки. Удаление необратимо;
не включай `/deletebot` в список команд самого Лабби.

## Порядок настройки

Для токена уже созданного бота отправь BotFather `/token` и выбери своего бота
из списка. В интерфейсе эта команда находится в разделе **Bot Settings**.
Если бота ещё нет, сначала выполни `/newbot`: BotFather попросит имя и username,
после чего выдаст токен. Сохрани его в `BOT_TOKEN` локального `.env`.
Ключ OpenRouter создаётся отдельно и хранится в `OPENROUTER_API_KEY`.

В чате с [BotFather](https://t.me/BotFather) отправляй по очереди `/setname`,
`/setdescription`, `/setabouttext`, `/setuserpic`, `/setcommands`.
После каждой команды выбирай своего бота и отправляй соответствующий текст
или изображение. Профиль подготовлен локально; изменения в Telegram
автоматически не отправлялись.

По [документации Telegram](https://core.telegram.org/bots/features#edit-bots)
описание ограничено 512 символами, about — 120. Подготовленные тексты
проверены на эти ограничения.

## Модель

```dotenv
OPENROUTER_MODEL=nvidia/nemotron-3-super-120b-a12b:free
```

Модель выбрана в локальном `.env` и `.env.example`; LLM-клиент подключён к обработчикам.
Сведения о бесплатном тарифе и настройке ключа — в [инструкции окружения](local-environment.md).
