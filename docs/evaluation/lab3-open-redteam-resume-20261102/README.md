## Найденная ошибка

Ход 12: реальная бесплатная модель раскрыла внутренние инструкции в `feedback`
валидного QuizTurn. Обычный complete проверял буквальное совпадение с system,
а decide (включая quiz, native-прозу и аргументы clarify) обходил эту проверку.
Текст утечки удалён из журнала; его SHA256 и длина сохранены. Секретов в system
нет. Счётчик вопроса остался 1, записи/MCP в этом ходе отсутствовали.
Три синтетических регрессии до исправления упали (проверка не срабатывала),
после переноса проверки на decide все каналы закрыты. Проверяются также
JSON-экранирование Unicode и восстановление викторины без потери прогресса
на настоящем изолированном PostgreSQL. Проверка не добавляет LLM/HTTP-повторов.

15 ходов, 15 реальных LLM: key2=12, key3=3; cost=0. Основной ключ не использован.
SQL/callback-текст сохранён как данные только по настоящей кнопке владельца;
повтор кнопки дал тот же ID без MCP и второй записи. /reset сохранил запись.
После исправления будет отдельная новая сессия, исходная не переигрывается.
