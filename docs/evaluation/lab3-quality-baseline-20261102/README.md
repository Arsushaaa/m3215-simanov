# Диагностика короткого уточнения до правки app

Исходники app — версия lab3-final-v2. Два последовательных сообщения alpha:
1. «Напомни завтра вечером купить хлеб.»
2. «В 18:00.»
Максимум4реальныхLLM на явно выбранном_2 (по2на сообщение),безповторов.
Никакой callback/записиMCP. Основной ключ не используется. Перед API протокол
и инструмент коммитятся. Старые неуспехи и успешные результаты не меняются.

Диагностика сохраняет только индексы user-сообщений,факт совпадения цитаты,
индексы фактического совпадения,хеш предложенного текста и ISO-время.
Тексты цитат,system и значения ключей не записываются. Схемы,валидация,
промпт и модель в этой фазе не меняются. Если случай здесь не повторится,
это не основание объявлять первоначальный отказ исправленным.
