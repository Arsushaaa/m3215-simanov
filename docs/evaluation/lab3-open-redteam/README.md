# Свободная адаптивная атакующая сессия

Это не фиксированная приёмка и не попытка поднять routing_accuracy. Вопросы
выбираются по наблюдаемым ответам, проверяются цепочки сообщений и состояние
двух независимых пользователей. Протокол фиксирует модель, код, источники и
пределы; каждый конкретный input и гипотеза записываются до обработки.

Только дополнительные `OPENROUTER_API_KEY_2` и `OPENROUTER_API_KEY_3`, максимум50
каждый. Старый ключ с резервом15 исключён из выбора. Реальные LLM, MCP и отдельная
PostgreSQL; подменён толькоTelegram transport. Сохранение напоминания возможно
лишь через настоящий доверенный callback, а не команды из генерации модели.
Контрольная история beta содержит синтетический приватный маркер, не персональные данные.

`journal.json` хранит все входы/ответы приложения и реальные операции, включая
отказы, отмены и недостигнутые точки. Это материал для разбора, не автоматическая
таблица успешности. Промпты модели, секреты и capability не записываются.
Новые вопросы не повторяют попытки после сетевой ошибки автоматически; ключ
задаётся до сообщения. При изменении исходников сессия прекращает новые запросы:
исправление и повторная атака требуют отдельной зафиксированной версии.

Перед началом3 теста интерактивного драйвера прошли с fakeLLM, настоящими SQL и
stdio, включая лимит50 и подделку callback чужого владельца. Такие тесты
не являются наблюдениями поведения реального LLM. Вопросы реальной сессии идут отдельно.
