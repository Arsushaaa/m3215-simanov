# ЛР3: единственное изменение параметра после baseline

Первый реальный baseline v2: 13/15, стоимость0, 15 HTTP, source a7cd98f.
Сохранён полностью: [lab3-experiment-v2-results.json](lab3-experiment-v2-results.json).
Порог12/15 пройден. Два сбоя — `clarify_2` и `clarify_3`:

- «Сделай что-нибудь полезное.»: legacy_study вместо clarify, confidence0.5.
  Содержательной учебной задачи нет, нужен вопрос о желаемом действии.
- «Расскажи, что для меня важно сегодня.»: legacy_study вместо clarify, confidence0.9.
  Нет критерия важности/области и персонального контекста; обоснованное действие
  выбрать нельзя. Высокийconfidence не подтверждает правильность.

Обе ошибки безопасны в отношении MCP: legacy_study не имеет инструментов.
Однако свободный диалог вместо уточнения нарушает ожидаемый маршрут и может
потратить дополнительный LLM. Обе ошибки сохранены как ошибки, не переименованы
в корректные ответы. Всего13 правильных из исходных15, без исключения случаев.

**До следующего API** фиксируется v3: температура0.2 →0.0, остальные параметры,
модель, сообщения, схемы, Router-промпт, часы и все15 запросов неизменны.
Протокол хранит hash baseline-протокола и результатов. Гипотеза: уменьшение
вариативности может помочь на границе категорий. Альтернатива — смысловое
перекрытие общих разговоров и расплывчатых запросов, которое температура не
устранит. Результат не известен заранее и не гарантируется.

Повторяется **весь набор15**, в том числе оба ошибочных случая, чтобы изменение
не скрыло регрессии. Максимум ещё15 HTTP; в этой сессии после него будет не более30
из50 разрешённых модельных запросов. API-метаданные квоты после baseline пока
показывают прежние0/50, поэтому локальный счётчик вызовов учитывается отдельно.
Исходный результат не заменяется и случайные повторы ради лучшей оценки запрещены.

```bash
.venv/bin/python -m scripts.lab3_experiment run \
  --protocol docs/evaluation/lab3-experiment-v3-protocol.json \
  --output docs/evaluation/lab3-experiment-v3-results.json
```

заполняются после реального результатаv3. Настройка пользователя в Telegram
