# Замечания преподавателя: ЛР2 и ЛР3, 4 ноября 2026

## Зафиксированный исходный результат

Два точных вопроса преподавателя на прежнем приложении выбрали `legacy_study`
(2/2, два бесплатных LLM, cost=0). Это не воспроизводит описанное преподавателем
уточнение и не доказывает отсутствие случайного сбоя. Полные ответы до исправлений
не запрашивались: диагностировался только Router.
[Протокол и результат](teacher-feedback-20261104-baseline/results.json).

## Изменения

- MCP-discovery обновляется по list_changed и каждые 60 секунд. Схемы существующих
  параметров берутся с сервера; побайтное сравнение с локальными схемами удалено.
  Новые ограничения доходят до native/structured модели и проверяются при вызове;
  вход и исходный выход также проходят локальную семантическую проверку.
- Неизвестный инструмент не получает прав. Изменённая структура параметров
  изолирует только затронутый инструмент; её использование требует явного адаптера.
  Перебой discovery не завершает бота. Восстановление каталога не требует рестарта.
- Смена каталога до отправки останавливает устаревшую операцию. Уже отправленный
  запрос проверяется валидатором его снимка. Скрытых повторов/записей нет.
- Native Router требует `select_route`; конкретная тема достаточна для учебного
  ответа. Несовпадение DTO — `failed/INVALID_ROUTE`, а не притворное уточнение
  смысла понятного вопроса. Регулярки для интентов не добавлены.

## Повторная проверка

Результаты ещё не заявлены. План: прежние 12 запросов ЛР2 и 15 запросов Router ЛР3,
два точных вопроса преподавателя с полноценным ответом и шесть новых контролей.
Все старые результаты сохраняются. Ожидания модели не передаются, started-попытки
не повторяются. Платных моделей/fallback нет; основной ключ резервируется целиком.

Папки с суффиксом `unused-draft` — неиспользованные промежуточные протоколы
до правки оформления/завершения кода: 0 LLM и 0 результатов; это не успешные опыты.

Границы: автоматические тесты подменяют LLM/Telegram и погодный HTTP, отдельная
PostgreSQL/stdio настоящие. В опыте ЛР2 чтение останавливается перед MCP, запись
напоминаний/Telegram отсутствуют. Проверка ответов ЛР3 использует настоящий MCP
для учебных материалов, свежую память вместо пользовательской БД, без Telegram.
