# Предрегистрация реального эксперимента ЛР3

Замороженный протокол: [lab3-experiment-protocol.json](lab3-experiment-protocol.json).
Runner: `scripts/lab3_experiment.py`; тесты измерителя — `tests/test_lab3_experiment.py`.
Он проверен на **подменённых** ответах, которые не являются результатом модели.

До первого LLM необходимо закоммитить протокол вместе с измерителем. CLI проверяет
совпадение протокола с Git HEAD и SHA-256 каждого Python/SQL runtime, корпуса,
фикстуры, зависимостей, измерителя и исходного набора. Права и промпт между
случаями не меняются. Ожидания остаются только в проверяющем коде.

Фиксированная конфигурация: `nvidia/nemotron-3.5-super-vl:free`, native tool calling,
T=0.2, max_tokens=2048, reasoning выключен, контекст 6000 токенов, максимум 15 HTTP.
[Официальная карточка модели](https://openrouter.ai/nvidia/nemotron-3.5-super-vl:free)
проверена перед предрегистрацией: бесплатный endpoint и tools/tool_choice доступны.
Клиент дополнительно задаёт `provider.max_price.prompt=completion=0`; платного
fallback нет. Фактический cost сохраняется из usage, если провайдер его сообщил.
Если не сообщил, в отчёте `null`, без выдуманной измеренной стоимости.

Используется исходный набор **15/15** без правки вопросов или ожиданий, часы
12 октября 2026, 09:00 Europe/Moscow, пустая история. Это эксперимент выбора
маршрута, а не генерация ответов специалистов. Для каждого запроса запускается
производственный Router ровно один раз. Нет MCP, Telegram и персональных данных.
Город из исходного контекста не требуется для выбора роли и не подменяет запрос.

Порог — минимум 12/15. Сохраняются target, confidence, latency, hash фактического
payload, usage и ограниченный ответ Router. HTTP-ошибки, тайм-ауты, неправильный
DTO и прерванные начатые попытки входят в знаменатель как ошибки. Автоматического
повтора и смены модели нет. Если качество ниже порога, сначала описывается одна
причина/изменение и отдельный протокол; исходный прогон остаётся в истории.

До запуска проверяется квота на все ещё не начатые запросы. На подготовке API
ключа вернул `limit=50, used=49, remaining=1`; генерация не запускалась. Это
блокирует эксперимент, но не является неуспешным ответом модели. Начатая попытка
сначала записывается в checkpoint, поэтому повтор CLI не повторяет её после сбоя.
Одновременный запуск защищён файловой блокировкой.

Воспроизведение после появления минимум 15 свободных запросов:

```bash
source scripts/env.sh
.venv/bin/python -m scripts.lab3_experiment run
```

Команда сохраняет `lab3-experiment-results.json`. До полного реального результата
нельзя объявлять порог выполненным, ставить финальный `lab3` или заменять его
результатами тестов измерителя. Текущий статус нужно читать из JSON, не из этого
первоначального описания протокола. Исторические отчёты ЛР2 не переписываются.
