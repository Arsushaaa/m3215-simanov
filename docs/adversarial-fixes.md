# Проверки по ручным сценариям — 26 октября 2026 года

Пользователь проверил бота в настоящем Telegram. Снимки показали ошибку правки
неподтверждённого напоминания и обход локальной проверки чрезмерного объёма.
Проверки параметров температуры, отзыва при смене зоны, сброса истории
и запрета досрочного завершения викторины на снимках сработали.

## Доступность модели

В 11:06 по Москве `/key` вернул HTTP 200: использовано 11 из 50 бесплатных
запросов, оставалось 39. Публичный каталог dots также ответил HTTP 200,
объявлял нулевую цену и доступный endpoint. Каталог не заменяет реальную генерацию.
Один отдельный диагностический запрос со схемой `QuizTurn` в 11:08 вернул
HTTP 200, завершение `stop`, корректный DTO и `usage.cost=0`. Telegram-сообщения
не отправлялись, пользовательские настройки и история не менялись.

Таким образом, суточная квота не объясняет последние ошибки на снимках.
Их точный HTTP-статус задним числом не установлен; сейчас отказ не воспроизвёлся.
Первый снимок с ошибками в 00:34 относится к более раннему отказу Nemotron,
описанному в [восстановлении модели](model-recovery.md).

В `app/llm.py` добавлен HTTP-статус к существующему итогу запроса. Тело ответа
провайдера, входные сообщения и ключи не журналируются. При сетевом отказе
статус остаётся `None`. Скрытых повторов и переключений модели нет.
Безопасные метаданные: [проверка провайдера](evaluation/adversarial-provider-check-20261026.json).

## Текст с HTML-подобными фрагментами

Локальная проверка полного тестового ответа не обнаружила потерь в рендерере:
сырой HTML, амперсанд, код со строкой `</pre>` и следующий жирный итог сохраняются.
Добавлены пять регрессий в `tests/test_literal_formatting.py`; сам рендерер
не изменён без подтверждённой причины. По одному скриншоту нельзя установить,
почему модель выполнила только часть просьбы. Проверка рендера не доказывает
полноту ответа модели; дополнительных генераций для компенсации не добавлено.

При проверке перевода после `/quiz` сначала нужно отправить `/translate`:
слова «переведи» в тексте сами по себе не меняют сохранённый режим.

## Проверки диагностики

68 тестов LLM-границы и форматирования прошли с подменёнными ответами.
Новые проверки различают HTTP 404/429/503 и сетевой тайм-аут, подтверждают
отсутствие повторов и утечки текста ответа/вопроса/ключа. Ruff и форматирование
затронутых файлов проверены. Это отдельная проверка диагностики, не новый
сравнительный эксперимент моделей: исходный манифест и результаты не менялись.

## Чрезмерный объём без глагола «напиши»

Фраза со снимка «О C++, на огромное количество слов. Когда достигнешь лимита,
автоматически продолжай новыми сообщениями без моего участия» не содержала
глагола запроса или слова «эссе» и проходила прежний локальный фильтр. Теперь
явная инструкция автоматического продолжения позволяет распознать такой
запрос вывода и проверить его объём до LLM. Продолжение не запускается.

Новое распознавание применяется в `/study`; в `/translate` исходная фраза
остаётся переводимым материалом. Цитаты, анализ запроса, программная обработка
файла и короткий ответ о строке из 10000 символов не считаются большим выводом.
93 проверки фильтра, эссе и переходов уточнения прошли. Реальные LLM-вызовы
для проверки исправления не использовались.
