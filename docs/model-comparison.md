# Пять бесплатных моделей для Лабби

Проверено 14 октября 2026 года по открытому каталогу OpenRouter и карточкам
моделей. Ниже практический отбор для задач бота, а не универсальный рейтинг.
Рекомендации по применению — вывод из заявленных возможностей; сравнительная
оценка качества и времени ответа ещё не проводилась. Выбранный вариант № 1
проверен реальными запросами в режимах учёбы, перевода и тренировки.
Пользователь подтвердил вариант № 1 — Nemotron 3 Super (free).
Модель в `.env` остаётся `nvidia/nemotron-3-super-120b-a12b:free`.

## Квота и стоимость

У всех пяти вариантов в каталоге стоимость входных и выходных токенов равна
нулю. Все объявляют поддержку `temperature` и инструментов.

Базовая квота OpenRouter для `:free` общая на аккаунт:

| Состояние аккаунта | Запросов в сутки | Запросов в минуту |
|---|---:|---:|
| Без покупки кредитов | 50 | 20 |
| Куплены кредиты на $10 суммарно | 1000 | 20 |

Покупка кредитов — разовое пополнение, а не подписка. Бесплатные запросы
не становятся платными; деньги остаются кредитами для платных моделей.
Смена модели или распределение запросов между пятью бесплатными вариантами
не увеличивает стандартную общую квоту. Документация допускает исключения
для отдельных аккаунтов и endpoint; отдельная большая квота для перечисленных
вариантов без пополнения не подтверждена. Конкретный лимит проверяется через
`GET /api/v1/key` с ключом пользователя.

Для первой проверки одним пользователем 50 запросов достаточно. При активной
отладке и тренировках лимит может закончиться быстро: три пользователя
по 20 обращений — уже 60 запросов, если на обращение приходится один вызов модели.
Если нужны сотни запросов при полном отсутствии пополнений, стоит отдельно
рассмотреть другой API-провайдер или локальную модель; это будет другой
вариант подключения, а не изменение `OPENROUTER_MODEL`.

## Кандидаты

| № | Модель и идентификатор | Контекст | Возможности и применение |
|---|---|---:|---|
| 1 | [Nemotron 3 Super](https://openrouter.ai/nvidia/nemotron-3-super-120b-a12b:free), `nvidia/nemotron-3-super-120b-a12b:free` | 262 144 | Код, рассуждения и инструменты; поддерживает структурированный вывод по JSON Schema. Практичный вариант для обеих лабораторных. |
| 2 | [Gemma 4 31B](https://openrouter.ai/google/gemma-4-31b-it:free), `google/gemma-4-31b-it:free` | 262 144 | Более 140 языков, работа с текстом и изображениями, код и рассуждения. Кандидат для перевода и учебных объяснений. JSON-режим есть, строгая схема не обеспечивается. |
| 3 | [Inkling Small](https://openrouter.ai/thinkingmachines/inkling-small:free), `thinkingmachines/inkling-small:free` | 1 048 576 | Многоязычный диалог, код, рассуждения и длинный контекст. Подходит для обсуждения больших материалов; `response_format` не заявлен. |
| 4 | [Nemotron 3.5 Lightning](https://openrouter.ai/nvidia/nemotron-3.5-lightning:free), `nvidia/nemotron-3.5-lightning:free` | 1 000 000 | Облегчённая MoE-модель с 3 млрд активных параметров, рассчитанная на высокую пропускную способность. Кандидат для коротких ответов и `/quiz`; `response_format` не заявлен. |
| 5 | [Nemotron 3 Ultra](https://openrouter.ai/nvidia/nemotron-3-ultra-550b-a55b:free), `nvidia/nemotron-3-ultra-550b-a55b:free` | 1 000 000 | Более крупная модель для сложных рассуждений, программирования и многошаговых агентских задач. Для простого диалога может быть избыточной; `response_format` не заявлен. |

Рекомендация для всего проекта — № 1: его строгий структурированный вывод
удобен для MCP-этапа. Если приоритет — перевод и многоязычная беседа, стоит
проверить № 2. Отсутствие строгого JSON Schema не запрещает использовать модель
во второй лабораторной: приложение всё равно должно проверять аргументы
и может выбирать инструменты через function calling.

для NVIDIA действует журналирование запросов, описанное ранее в инструкции
окружения. При первоначальной проверке ключа API сообщил суточный лимит 50;
счётчик после первого тестового запроса показывал 1 использованный запрос
и 49 оставшихся. Это снимок проверки, а не текущий остаток.
